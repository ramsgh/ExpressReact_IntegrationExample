# Day 32 - REST API Design, Versioning & Status Codes

This project includes five independent Express APIs and one React learning console that demonstrates all of them.

## Run with React

Install packages:

```bash
npm install
```

Start one or more Express servers in separate terminals:

```bash
npm run prog1
npm run prog2
npm run prog3
npm run prog4
npm run prog5
```

Start the React interface in another terminal:

```bash
npm run react
```

Open the URL printed by Vite, usually `http://localhost:5173`.

You can run only the servers needed for the React tab you are using.

## React demos

- REST & Versioning: GET `/api/v1/products` on port 3001
- Success Codes: GET, POST, and DELETE items on port 3002
- Client Errors: 400, 404, and 409 responses on port 3003
- Authentication: 401 and 403 responses on port 3004
- Server Errors: standardized 500 response on port 3005
